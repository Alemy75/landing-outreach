# Ателье «Профи», Ярославль

Статический лендинг без сборки. Все ресурсы расположены внутри этой папки, ссылки относительные. Файлы можно разместить на GitHub Pages или другом статическом хостинге.

Демо: https://alemy75.github.io/landing-outreach/landings/profi-atelier/

Для локального просмотра выполните `npm run dev` из корня репозитория и откройте http://127.0.0.1:4173/landings/profi-atelier/.

## Содержание

- `index.html`, `styles.css`, `script.js` — сайт, адаптивная вёрстка и слайдер услуг.
- `images/01-profi/` — 21 изображение в WebP. Главный фотосюжет и два снимка жакетов предоставлены пользователем; фото каталога перенесены с сайта ателье.
- `assets/` — локальные шрифты Inter и EB Garamond, лицензии, иконка.
- `data/profi-services.json` — 17 услуг, цены, исходные URL и дата проверки.
- `tools/prepare-seo.mjs` — обновление canonical, Open Graph и sitemap при смене адреса.

Дизайн: светлый фон, тёплый чёрный, шрифты с засечками, нейтральные поверхности, мягкие анимации. Слайдер поддерживает свайп, мышь и клавиатуру; учитывается reduced-motion. Первые пять фото заполняют кадр, остальные показаны целиком на нейтральном фоне.

Контакты и услуги взяты из карточки ателье на Яндекс Картах и каталога https://atele-profi.clients.site/. Цены проверены 21 октября 2026 года. Условия конкретного заказа следует уточнять в ателье. Главная иллюстрация не заявлена как документальная фотография именно этого ателье.
