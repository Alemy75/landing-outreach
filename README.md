# landing-outreach

Демо лендингов. Каждый сайт хранится в отдельной папке и работает без сборки.

| Лендинг | Исходники | Демо |
| --- | --- | --- |
| Ателье «Профи», Ярославль | [landings/profi-atelier](landings/profi-atelier/) | [Открыть сайт](https://alemy75.github.io/landing-outreach/landings/profi-atelier/) |

## Локальный просмотр

`npm run dev` → http://127.0.0.1:4173/

## Добавление лендинга

Создайте `landings/<название>/index.html`, храните стили, скрипты и изображения внутри той же папки. Используйте относительные ссылки на ресурсы. Добавьте ссылку в корневой `index.html` и таблицу выше.

GitHub Pages публикует ветку `main`, папку `/`. Корневая страница — каталог демо; каждый лендинг доступен по собственному адресу. Все растровые изображения ателье сохранены в WebP.

Локальные выгрузки, таблицы контактов и отчёты в репозиторий не включаются.
